#### ずれの切り分け（4 つの検算）

1. **組成側は合っている。** JP2004 が明記する平衡 CH4 転化率 55% / 57% に対し、
   本実装は 55.5% / 57.4%。いずれも特許の 2 桁表記の丸め幅の内側。
2. **熱力学データは JANAF 級。** ΔG°(2CO → C + CO2) @ 298.15 K は本実装 −120.04 kJ/mol
   に対し CODATA/JANAF −120.02。黒鉛 S°(298) 5.734（JANAF 5.740）、S°(1000) 24.451
   （24.457）、Cp(298) 8.528（8.517）。ΔG°(CH4 ⇌ C + 2H2) @ 298.15 K も +50.53
   （既知値 +50.7）。
3. **出典を替えても動かない。** ΔG°(2CO → C + CO2) [kJ/mol]:

   | 出典 | 650 ℃ | 850 ℃ | 875 ℃ |
   |---|---|---|---|
   | gri30 + graphite.yaml（本実装） | −8.791 | 26.236 | 30.588 |
   | NASA9 gas + NASA condensed | −8.791 | 26.236 | 30.588 |
   | methane_pox_on_pt + graphite | −8.949 | 26.045 | 30.393 |
   | 古典式 −170700 + 174.5·T | −9.610 | 25.290 | 29.652 |
   | **特許が要求する値（群 A から逆算）** | **−7.977** | **25.604** | — |

   まともな出典はどれも **0.8 kJ/mol 以内**で一致する。特許の数値を再現するには
   **ΔH を +7.4 kJ/mol、ΔS を +7.2 J/mol/K** ずらす必要があり、そんな値を出す
   出典は無い（Boudouard の ΔH°、ΔS° は 1950 年代の NBS 値でも現代値と 1 kJ 以内）。
4. **同じ温度でも比が組成で変わる**（850 ℃・群 A で 1.033〜1.098、丸め幅を超える）。
   K_B の誤差なら同一温度の全点が同じ比になるはずで、**組成側の前提も違う**ことを意味する。
   実際、JP2012 表1 の物質収支から出口を計算すると本実装は dry で CH4 7.7% に対し
   特許の表は 9%。**特許のリフォーマー出口は完全平衡ではない**（approach がある）。

#### 結論

- **熱力学データを差し替えても「完全一致」にはできない。** 残差の主因は
  (a) 特許値が 2 桁表記（Ac = 0.09 なら丸めだけで ±5.6%）、
  (b) 特許側の組成の前提（平衡への接近度・実天然ガスの C2+）、
  (c) 千代田の社内相関／シミュレータの中身が不明、の 3 つ。
- 2 パラメータ（ΔH, ΔS）の経験補正を当てると残差は ±10% → ±5% に下がるが、
  丸め幅に収まるのは 12 点中 3 点だけ。**物理的な裏づけも無いので採用しない。**
- **照合として言えること**: Ac 0.09〜2.8（30 倍）・650〜875 ℃・0.5〜2.0 MPaG の
  21 点で **±13% 以内**、大小関係はすべて一致。組成側は独立に検算でき、熱力学データは
  JANAF と一致している。定義（Boudouard 1 本）も平衡気相では本実装の 3 経路最大値と
  厳密に同値（ばらつき ≤ 2e-12）。

⚠️ **群 B の但し書き**: JP2012 表1 の天然ガスは CH4 91.5 / C2 4.2 / C3 2.5 / C4 1.3 /
C5 0.4 / C6 0.1 mol%（H/C = 3.736、純 CH4 なら 4.0）。S/C・CO2/C の分母が
この C2+ を含むため、**CH4 = 1 と置く解釈は近似**。しかも同じ表から S/C は全炭素基準
（1.49）、CO2/C は CH4 炭素基準（0.245）と読めてしまい、特許内で基準が揃っていない。

#### ★Stull 1969 が無くても「平衡定数の版差」仮説は閉じられる（2026-08-29）

**根拠 1 — NIST が CO・CO2 の値をいつ確定したか。**
NIST Webbook（Chase 1998 = NIST-JANAF 第 4 版）の CO・CO2 のページには、
標準生成エンタルピーと標準エントロピーの注記として
**"Data last reviewed in September, 1965"** とある。
つまり **Stull 1969 が参照できた値と、現行 JANAF の値は同じ年代のもの**。
CO・CO2・黒鉛は 1950〜60 年代にすでに確定していた量なので、
**「1969 年の本だから古い」では 4〜6% もの K の差は作れない**。

**根拠 2 — Cantera と独立の第三者データでも一致する。**
NIST Webbook の Shomate 係数（CO・CO2）と黒鉛から ΔG°(2CO → C + CO2) を組み直すと:

| T [K] | NIST-JANAF Shomate | Cantera (gri30) | 差 [kJ/mol] | K の比 |
|---|---|---|---|---|
| 923.15 | −8.817 | −8.791 | −0.027 | 1.0035 |
| 1123.15 | 26.203 | 26.236 | −0.034 | 1.0036 |
| 1148.15 | 30.554 | 30.588 | −0.034 | 1.0036 |

**0.034 kJ/mol（K で 0.4%）**しか違わない。特許の数値が要求する
ΔH +7.4 kJ/mol・ΔS +7.2 J/mol/K とは桁が違う。
（再現: `examples/example_chiyoda_patent_check.py` の検算 3b）

**根拠 3 — 数表の刻み幅でも説明できない。**
1969 年の数表は 100 K 刻みが標準なので「ノード間を直線内挿したずれ」も試したが、
650 ℃ で +4.6%、850 ℃ で +2.6%、875 ℃ で +3.5% と**3 温度とも同符号**で、
観測されている符号反転（650 ℃ −10% / 850 ℃ +7%）は作れない。
log K を 1/T で内挿すれば誤差は 0.1% 以下になる。

→ **Stull 1969 を入手しても結論は変わらない見込み。** 入手する価値は

## 2. 炭素活量 a_C の定義（現行実装の根拠）

**§0-2 の特許 WO2012140994A1 で千代田自身の定義（Boudouard 経路）が確認できた**ので、
実装の根拠は「教科書的定義」から「一次資料で確認済み」に格上げされている。
§1-3 の Udengaard（線図としての一次出典）は依然未入手だが、優先度は下がった。

炭素析出を起こしうる 3 反応それぞれについて、固体炭素（黒鉛）の活量を求める。
千代田は B のみで定義しているが、**平衡気相では 3 経路が一致する**ので
改質器出口に適用する限り同値（→ `carbon_activity.html` §2）。

| # | 反応 | a_C |
|---|---|---|
| B | Boudouard: 2CO ⇌ C(gr) + CO2 | a_C = K_B · p_CO² / p_CO2 |
| M | メタン分解: CH4 ⇌ C(gr) + 2H2 | a_C = K_M · p_CH4 / p_H2² |
| R | CO 還元: CO + H2 ⇌ C(gr) + H2O | a_C = K_R · p_CO·p_H2 / p_H2O |

- **a_C > 1 なら炭素析出が熱力学的に有利**、a_C ≤ 1 なら析出しない。
- 分圧は **atm 基準**（Cantera の `reference_pressure` が 101325 Pa のため）。
- 3 つのうち**最大値**で判定する（どれか 1 つでも 1 を超えれば析出しうる）。

平衡定数は Cantera の標準生成ギブズエネルギーから計算する:
気相は `gri30.yaml`、固体炭素は `graphite.yaml`（相 `C(gr)`）。

### 検算（2026-08-01 実施）

| T [K] | K_B (Boudouard) | K_M (CH4分解) | K_R (CO還元) |
|---|---|---|---|
| 773.15 (500℃) | 2.4296e+02 | 4.7347e-01 | 4.7471e+01 |
| 973.15 (700℃) | 9.9978e-01 | 7.7947e+00 | 6.2037e-01 |
| 1123.15 (850℃) | 6.0235e-02 | 3.4111e+01 | 6.5862e-02 |
| 1173.15 (900℃) | 2.7833e-02 | 5.1449e+01 | 3.5432e-02 |
| 1273.15 (1000℃) | 7.1738e-03 | 1.0646e+02 | 1.1877e-02 |

妥当性の確認:
- Boudouard は**発熱**反応なので高温で K が下がる（500℃ 2.43e+2 → 1000℃ 7.17e-3）✓
- メタン分解は**吸熱**なので高温で K が上がる（500℃ 4.73e-1 → 1000℃ 1.06e+2）✓
- **K_B ≈ 1.000 が 973.15 K（700℃）** で得られる。これは Boudouard 平衡の
  古典的な基準温度と一致する ✓

**(a) 3 経路の一致（本実装 §2 の主張）を 1961 年に実演している**

理論計算のくだり（2・1 炭素析出限界）で、活量比を 3 つ定義して平衡定数と比較している:

    A3 = a_CH4 / a_H2²        K3 : CH4 = C + 2H2      ← 本実装の M（メタン分解）
    A4 = a_CO·a_H2 / a_H2O    K4 : C + H2O = CO + H2  ← 本実装の R（CO 還元・逆向き）
    A5 = a_CO² / a_CO2        K5 : 2CO = C + CO2      ← 本実装の B（Boudouard）

> 曲線 A3 および A4 をそれぞれ平衡定数の値 K3 および K4 で切った交点を求めると、
> これからその温度および炭酸ガス-メタン比における**最小水蒸気量**が得られる。
> また次の(4)式を考え、2CO = C + CO2 同じように活量比 A5 = a_CO²/a_CO2 の曲線をつくり、
> 平衡定数 K5 との交点からも**同じ値が得られる**。

- **「3 経路のどれで解いても同じ」を一次資料が明言している。**
- しかも解き方が **a_C = 1 を課して最小水蒸気量を求める**形で、本実装の
  `Problem.constrain_carbon_activity`（等式で限界そのものを解く）と同じ使い方。

**(b) 実験と理論の一致範囲（本実装の運転温度がここに入る）**

- 実験: 595 / 706 / 816 / 926 ℃、触媒層通過後に窒素置換 → 窒素-酸素で析出炭素を燃焼し
  CO2 として定量（表 4 に 32 点）。析出量が 0 になる点へ外挿して析出限界点とする。
- 結論: **「温度 816 ℃以上では炭素析出曲線の実験値と理論値はほぼ一致するが、
  706 ℃以下では全般に実験値の方が低く、低温になるにつれて炭素析出し難い」**
- 考察の理由づけも本実装の前提と同じ:
  **「高温の場合、たとえば 816 ℃以上ではすべての反応がほとんど平衡に達すると
  考えられるので、この場合はほとんど理論値と同じ傾向を示す」**
- → **運転温度 835〜875 ℃ は「平衡計算で析出境界を予測してよい」範囲**。
  低温側のずれは「理論より析出しにくい」向きなので、判定は保守側に外れる。

**(c) 副次的に使える知見**

- 析出限界からの距離と析出炭素量は**直線関係**（表 2・図 5）。
- 水蒸気と炭酸ガスの効き方の比 C_R は温度とともに 1 に近づく（表 6。595 ℃ で 0.15、
  926 ℃ で 0.97〜1.01）。**低温ほど H2O の方が効き、高温では H2O と CO2 が等価**。
- メタン-酸素反応の析出限界値とも一致することを表 5 で確認している。
